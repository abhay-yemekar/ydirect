# yDirect public roadmap

This roadmap communicates product direction, not guaranteed dates. Priorities may change after user feedback, Chrome platform changes, security review, legal review, or operational learning.

## Now — public launch readiness

- [x] Manifest V3 extension identity and permanent Chrome Web Store item ID
- [x] Account sign-in, local-first snippet library, folders, search, and one-click copy
- [x] JSON, encrypted JSON, and Excel portability
- [x] Optional cloud backup with latest and previous recovery points
- [x] Verified-account workspace roles and selective folder/snippet sharing
- [x] Public privacy, terms, support, uninstall, and changelog pages
- [x] Chrome Web Store submission for version `1.3.1`
- [ ] Chrome Web Store approval and owner-controlled public publishing
- [ ] Post-launch feedback triage and onboarding refinements

## Next — confidence and usability

- [ ] Guided first-run onboarding with sample snippets
- [ ] Clearer backup-health and recovery guidance
- [ ] Improved keyboard-first navigation and shortcut discovery
- [ ] Additional safe, fake-data product walkthroughs
- [ ] Accessibility review against current WCAG guidance
- [ ] Public compatibility matrix based on verified browser/page testing

## Later — collaboration depth

- [ ] Optional contribution permission separate from view access
- [ ] Manager-visible resource activity history
- [ ] Notifications for member contributions and important workspace changes
- [ ] Recovery window for manager-deleted contributions
- [ ] More granular workspace membership controls

## Exploring

- Browser support beyond Chrome where platform APIs and policy requirements align
- Search improvements for larger libraries
- More import/export formats driven by real user needs
- Team governance features that remain understandable for small teams

## Explicit non-goals for the current release

- Storing passwords, private keys, payment-card data, or other highly sensitive secrets
- Advertising or selling user data
- Automatic reading of page contents or browsing history
- Persistent access to every website
- Paid subscriptions or in-product payments in version `1.3.1`

## Influence the roadmap

Open a [feature request](https://github.com/abhay-yemekar/ydirect/issues/new?template=feature_request.yml) with the problem you are solving, who experiences it, and what success would look like. Please do not submit security vulnerabilities in public issues; follow [SECURITY.md](SECURITY.md).
