# Support

## Product help

Start with the public [yDirect Support Center](https://inksl-ay.firebaseapp.com/support.html) for account access, verification, workspace sharing, shortcuts, backup, import/export, and safe troubleshooting.

If the issue remains, email [support@ydirect.tech](mailto:support@ydirect.tech?subject=yDirect%20Support%20Request).

## What to include

- yDirect version;
- Chrome version and operating system;
- whether the issue occurs in the popup, attached workspace, or both;
- clear steps to reproduce;
- expected and actual behavior;
- an edited screenshot or short recording with personal and snippet information hidden.

## Do not include

Never send:

- passwords or one-time codes;
- verification, reset, or sign-in links;
- authentication tokens or browser-profile data;
- private keys, recovery codes, or payment information;
- sensitive snippet content or unredacted user/customer data.

yDirect Support will not ask for these items.

## GitHub Issues

Use GitHub Issues for public, non-sensitive bug reports, feature requests, documentation corrections, and reproducible usability feedback.

Do not open a public issue for a suspected security vulnerability, privacy incident, account-specific problem, or anything containing sensitive data. Follow [SECURITY.md](SECURITY.md) instead.

## Account and privacy requests

For access, correction, deletion, portability, restriction, objection, or consent-withdrawal questions, email [support@ydirect.tech](mailto:support@ydirect.tech?subject=yDirect%20Privacy%20Request). Identity verification may be required before an account request is fulfilled.
