## Approved descriptions

### One line

yDirect is a Chrome snippet manager that keeps reusable text organized, searchable, portable, and ready to copy without leaving the current tab.

### Short description

yDirect helps people save, organize, find, copy, export, back up, and selectively share frequently reused text from Chrome's native side panel. It opens on demand from the toolbar, `Alt+S`, or an optional page shortcut.

### Full description

yDirect is a local-first snippet manager for Chrome. It gives support, sales, recruiting, development, operations, writing, and study workflows a focused place for reusable text. Users can organize snippets in folders, search and copy quickly, create portable JSON or Excel exports, enable optional limited cloud backup, and selectively share folders or snippets with verified accounts. The workspace runs in Chrome's native side panel; temporary page access is limited to the optional user-invoked shortcut, and yDirect does not request persistent access to every website.

## Screenshot and claim safety

Use only approved screenshots containing synthetic or clearly non-sensitive sample data. Before publishing a new asset:

- remove real email addresses, account details, tokens, IDs, private URLs, and unrelated browser content;
- use placeholder values instead of real API keys or credentials;
- confirm the feature exists in the referenced release;
- say that visual masking is not encryption;
- distinguish local library data, cloud workspace data, and optional cloud backup;
- do not invent user counts, ratings, awards, endorsements, or performance claims.
